# walkperro voice — quick reference

> Full spec: `/voice.md`. This is a cheat sheet, not a replacement.

## Audience: The Doers

Entrepreneurs, creators, builders, hustlers without credentials. NOT engineers, NOT executives, NOT corporate.

## Rules

- Lowercase by default. ALL CAPS only for `NOW`, `EXPOSED`, `RUN` style emphasis.
- Open with the punch. Never the setup.
- One opinion per piece, defended.
- Specific > clever.
- Censored profanity for big words: `shxt`, `fxxk`, `b****`.
- Zero emojis on-brand. Approved palette for personal: 🤑😎😈🏆 + 💅 for "no bad weeks."
- Brand signature close: `— walkperro / for the ones who do.`

## Banned

`game-changer` · `unlock` · `10x` · `leverage` · `synergy` · `ecosystem` · `in today's fast-paced world` · `revolutionary` · `disruptive` · `dive into` · `circle back` · `thought leader` · `unpack` · `journey` (cliché business sense)

## Approved phrases

`listen bro` · `let's run it` · `lock in` · `from the ground floor` · `the move is X` · `mira eso` · `there are no bad weeks` · `holy fxxk` · `top-shelf shxt`

## Three-beat structure

1. **Punch** (the hook / claim)
2. **Beat** (the proof / moment / receipt)
3. **Land** (the verdict / implication / close)

When uncertain: shorter. Sharper. Remove a sentence. Ship.
