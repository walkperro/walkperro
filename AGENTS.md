# Revenue Leak Hunter Rules (WalkPerro)

## Goal
Run a full site audit and produce a Revenue Leak Report (CRO + SEO + Performance + Trust). Prioritize fixes that improve conversion and organic traffic.

## Constraints
- Do not introduce HIPAA/PII collection.
- Do not add new paid services.
- Prefer minimal code changes with maximum impact.
- Always provide: (1) evidence, (2) fix, (3) exact file paths.

## Output format
1) Executive Summary (top 5 leaks)
2) Metrics snapshot (Lighthouse-like)
3) Leak list (Impact / Effort / Evidence / Fix)
4) Fix Plan (48 hours / 7 days / 30 days)
5) Patch diff summary
